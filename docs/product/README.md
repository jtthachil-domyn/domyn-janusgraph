The current product target is **Internal Beta: single-node server first**. The
embedded SDK and cloud demo shells come after the server gate is boring.

Before starting any tranche, read the production-grade master plan, the Internal
Beta ledger, known limits, and production readiness. Before closing any tranche,
update checklist status, evidence, and known limits. No workaround may be
treated as product behavior.
